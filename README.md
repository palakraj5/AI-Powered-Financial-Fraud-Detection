# AI-Powered Financial Fraud Detection

An AI-powered web application for detecting potentially fraudulent financial transactions using Machine Learning.

## 📌 Project Overview

Financial fraud is a major challenge in digital transactions. This project uses Machine Learning to analyze transaction-related information and predict whether a transaction is *legitimate or potentially fraudulent*.

The project provides a simple web interface where users can enter transaction details and receive a fraud detection result.

## 🚀 Features

- 🤖 Machine Learning-based fraud detection
- 📊 Transaction analysis
- 🌐 User-friendly web interface
- ⚡ Fast prediction results
- 🔐 Fraud/legitimate transaction classification
- 📁 Organized backend and frontend structure

Installation & Setup
1. Clone the repository
git clone https://github.com/palakraj5/AI-Powered-Financial-Fraud-Detection.git
2. Navigate to the project directory
cd AI-Powered-Financial-Fraud-Detection
3. Create a virtual environment
python -m venv venv
4. Activate the virtual environment
Windows:
venv\Scripts\activate
5. Install dependencies
pip install -r requirements.txt
6. Run the application
python Backend/app.py
Then open the local URL shown in the terminal, usually:
http://127.0.0.1:5000
🔍 How It Works
User enters transaction information.
The application processes the input data.
The data is scaled/preprocessed using the trained scaler.
The trained Machine Learning model analyzes the transaction.
The system predicts whether the transaction is potentially fraudulent or legitimate.
The prediction is displayed to the user through the web interface.
Objective
The main objective of this project is to demonstrate how Artificial Intelligence and Machine Learning can be used to identify potentially fraudulent financial transactions and assist in improving financial security.
